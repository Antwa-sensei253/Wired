# Wired_

> A next-generation local automation daemon for PC and mobile.

Control your digital environment through a unified voice and terminal interface — powered by Gemini AI. No cloud account required. Free and open source.

---

## Features

- 🎙️ **Voice Control** — Natural language to shell commands
- ⚙️ **Automation Engine** — Multi-step macros and cron-style scheduling
- 📱 **Mobile Link** — Control your PC from your phone via QR pairing
- 🤖 **AI Core** — Gemini-powered script generation, diagnostics, and chat
- 🔒 **Privacy First** — 100% local processing by default
- 🧩 **Plugin SDK** — 500+ community extensions

## Getting Started

Just open `index.html` in your browser — no build step or server required.

To enable AI features (Neural Link), add your Gemini API key to the `apiKey` variable at the bottom of `index.html`.
