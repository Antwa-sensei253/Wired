التوثيق // v1.2

مرحبًا بك في الأرشيف. Wired هو خادم محلي يعمل جسرًا بين طرفيتك وملفاتك وصوتك. يتحدث بلغتك — حرفيًا.

ملاحظة: الإصدار 1.2 يدعم Gemini 1.5 لتحسين حفظ السياق عبر الجلسات.

نظرة عامة على الهيكل

┌─────────────────────────────────────────┐ │ WIRED ARCHITECTURE │ ├──────────────┬──────────────┬────────────┤ │ Voice Input │ Text Input │ Mobile App │ ├──────────────┴──────────────┴────────────┤ │ NLP Engine (Local) │ ├───────────────────────────────────────────┤ │ Wired Daemon (Core Process) │ ├────────────┬──────────────┬───────────────┤ │ Executor │ Gemini API │ Plugin Host │ ├────────────┴──────────────┴───────────────┤ │ OS / Shell Layer │ └───────────────────────────────────────────┘

يعمل الخادم كخدمة خلفية بحجم موارد ضئيل (~30ميجا RAM). كل معالجة الصوت تتم محليًا افتراضيًا. استدعاءات Gemini API اختيارية ومعلنة.

01_تثبيت_الحاسب

شغّل ملف التثبيت بصلاحيات المسؤول / sudo. اختر منصتك:

Windows — PowerShell (Run as Administrator) # iwr https://wired.net/install.ps1 -useb | iex Or with winget # winget install WiredDaemon
# macOS — Homebrew brew tap wired-dev/tap brew install wired # Or direct install curl -sL https://wired.net/install.sh | sudo bash
# Debian / Ubuntu curl -sL https://wired.net/install.sh | sudo bash # Arch Linux (AUR) yay -S wired-daemon # After install — enable the service systemctl enable --now wired

بعد التثبيت، يعمل Wired كخدمة خلفية. الوصول إليه من أي طرفية بالأمر wired.

02_ربط_الجوال

تأكد أن كلا الجهازين على نفس الشبكة المحلية، أو فعّل خدمة المرحّل المشفّر للتحكّم عن بعد.

  1. ثبِّت تطبيق Wired على جهازك المحمول.
  2. على حاسبك، شغّل wired link --generate
  3. امسح رمز QR الظاهر في الطرفية بتطبيق الجوال.
  4. اعتمد الاتصال على كلا الجهازين.

إمكانيات المحمول

  • إيقاف التشغيل / النوم / إعادة التشغيل عن بعد
  • التحكّم في الوسائط (Spotify, VLC, mpv)
  • تشغيل الماكروات عن بعد
  • الاتصال الصوتي — تحدّث عبر الجوال واسمع من الحاسب
  • نقل الملفات عبر الشبكة المحلية

ملاحظة: خدمة المرحّل اختيارية ومشفّرة بالكامل. بيانات اعتمادك لا تصل أبدًا إلى خوادم خارجية.

03_واجهة_برمجة_السكريبت

Wired يكشف عن JavaScript API لبناء الامتدادات. السكريبتات في ~/.wired/scripts/ وتُعاد تحميلها تلقائيًا عند الحفظ.

wired.on(event, callback)

استمع لمثيّر صوتي أو حدث نظام.

// Trigger when user says "good morning" wired.on('voice:good morning', async (ctx) => { await wired.say('Good morning. Loading your briefing.'); await wired.exec('open-briefing.sh'); });

wired.exec(command)

شغّل أمر طرفية بشكل غير متزامن، مع التقاط المخرجات.

const result = await wired.exec('df -h'); await wired.say(`Disk usage: ${result.stdout}`);

wired.say(text, options?)

نطق النص عبر محرك TTS النظام.

await wired.say('Build complete.', { voice: 'en-US-neural', speed: 0.9, pitch: 1.0 });

wired.schedule(cron, callback)

جدول مهام الأتمتة المتكررة باستخدام صيغة cron القياسية.

// Every weekday at 9am wired.schedule('0 9 * * 1-5', async () => { await wired.say('Standup in 15 minutes.'); await wired.exec('open-slack.sh'); });

04_استكشاف_الأخطاء

مشكلات شائعة وحلولها. لتقرير نظام كامل، شغّل wired diagnose.

تحقّق من صلاحيات الميكروفون: wired config --show | grep mic
اختبر الميك: wired diagnose --mic
تأكد تشغيل الخادم: wired status
أعد المعايرة: wired calibrate voice
1. تأكد أن كلا الجهازين على نفس الشبكة الفرعية.
2. تحقّق من جدار الحماية: المنفذ 7734 يجب أن يكون مفتوحًا.
3. أعد إنشاء رمز الاقتران: wired link --regenerate
4. فعّل وضع المرحّل لشبكات مختلفة: wired link --relay
غالبًا حلقة سكريبت جامحة. تحقّق: wired scripts --ps
أنهِ سكريبت متعلقًا: wired scripts --kill [script-name]
فعّل وضع توفير الطاقة: wired config set power-mode balanced
1. عيّن مفتاح API: wired config set gemini-key YOUR_KEY
2. تحقّق من الحصّة: wired diagnose --gemini
3. Wired يعمل بالكامل بدون إنترنت — عطّل وضع السحابة: wired config set cloud-mode false
1. تحقّق من التوقيع: wired plugin verify [name]
2. تحقّق من التوافقية: wired plugin info [name]
3. امسح الذاكرة المخبّأة: wired plugin cache --clear
4. للإضافات غير الموقّعة فقط: أضفعلم --unsafe (استخدم بحذر)

// المهمة

ما نبنيه

بدأ Wired كمشروع نهاية أسبوع — مشغّل سكريبت متحكّم فيه بالصوت بـ 200 سطر bash وغلاف Python. ثم نما ليصبح شيئًا أكبر: خادم ذكاء محلي يتعامل مع حاسوبك كامتداد لتفكيرك، لا كأداة تقاومك.

نبني لمن يتضجّر من الاحتكاك. كل نقرة بين النية والتنفيذ ضريبة. Wired يلغي تلك الضريبة. لا تبعية سحابية. لا اشتراكات. لا مراقبة. فقط خادم يفعل ما تقول.

// المبادئ

ما نؤمن به

01.

محلي أولاً، سحابي اختياري

بياناتك الصوتية لا تغادر جهازك افتراضيًا. ميزات السحابة اختيارية ومعلنة ومشفّرة.

02.

مفتوح المصدر للأبد

الخادم الأساسي سيظل دائمًا برخصة MIT. لسنا نبني فخًّا SaaS بطبقة مجانية كطُعم.

03.

المستخدمون المتقدمون أولاً

نُحسّن القدرة لا البساطة. المبتدئون مرحبٌ بهم لكننا لا نبسّط الأمور من أجلهم.

04.

لا أنماط مخادعة

لا إزعاجات، لا تحديثات قسرية، لا قياس بدون موافقة. نثق بمستخدمينا ويثقون بنا.
